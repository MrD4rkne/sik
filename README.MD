# Computer Networks

## Lectures

During this course, I learned how computer networks operate at every layer. We explored the architecture and protocols from the application layer down to the physical layer, gaining a comprehensive understanding of how data is transmitted and managed.

## Labs

In the lab sessions, we developed basic programs using C/C++ and system libraries. The assignments, which often involved completing partially implemented programs, taught us how to use networking libraries and efficiently handle multiple clients.
